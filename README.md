# Entre Fitas - Multimedia Project Website 🎬

A dedicated and responsive website built for the "Entre Fitas" integrated multimedia project. This project bridges the gap between creative design and web development, translating audiovisual guidelines into a functional, engaging digital ecosystem.

##  Tech Stack
* **HTML5:** Semantic structure and accessibility.
* **CSS3:** Custom responsive layout utilizing Flexbox and CSS Grid.
* **Vanilla JavaScript:** DOM manipulation and interactive UI elements.

##  Key Highlights
* **UI/UX Focused:** Interface built from scratch to match the project's visual identity.
* **Responsive Design:** Fluid adaptation across mobile, tablet, and desktop screens.
* **Clean Code:** Maintainable structure without reliance on external frontend frameworks.

##  How to run locally
1. Clone this repository or download the ZIP file.
2. Open the `index.html` file in your preferred web browser. No local server is required.
